# AcxiomCRM Frontend Prototype

This is a time-boxed frontend prototype based on the AcxiomCRM assignment specification.

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Demo login
Email: admin@acxiomcrm.com
Password: Admin@123

## Included
- Login/logout UI
- Dashboard KPI cards
- Chart.js lead and opportunity charts
- Customers, Leads, Opportunities
- Follow-ups and Activities
- Users & Roles
- Audit Log
- Reports
- Search/filter on list pages
- Client-side validation for email, phone, opportunity amount/probability and follow-up date
- Responsive Bootstrap UI

## Important
This is a frontend demonstration/prototype. The full assignment requires ASP.NET Core Identity, server-side validation, database persistence, server-side role authorization, REST APIs, audit logging and anti-forgery protection. Those backend requirements are not implemented in this 90-minute prototype.
